# GOONCAT logo options

- **logo-1.png — Mascot:** a deadpan tabby with bold espresso outlines peeking over an ivory blanket.
- **logo-2.png — Geometric icon:** a minimal sleepy cat with broad eyelids and a single folded blanket; selected for the wallet logo.
- **logo-3.png — Lettermark:** the GOONCAT ticker in two chunky interlocking rows, with cat ears and sleepy O counters.
- **logo-4.png — Minted badge:** an antique pewter and taupe medallion showing the reference cat in sculpted relief.
- **logo-5.png — Meme illustration:** an exaggerated, tilted sleepy tabby with comic impact rays and a pulled-up blanket.

All five are opaque 1024 × 1024 RGB PNGs drawn with the built-in Codex image-generation
tool, using the [creator's photograph](https://fxumiqjngmabtgvruvka.supabase.co/storage/v1/object/public/forum-attachments/posts/mv46jx6o-vq08o3.jpg)
as the visual reference. They preserve its gray-brown tabby, ivory blanket and muted palette.
The artwork was image-generated, not code-drawn; only resizing and inspection previews used code.
The exact prompt set is recorded in [PROMPTS.md](PROMPTS.md).

**Draft count: five, one per option; all five retained, none discarded.** Each option was
inspected at 64 pixels against light and dark backgrounds. The selected icon was also
inspected as a 32-pixel circle on both backgrounds. [../artifacts/logo.png](../artifacts/logo.png)
is byte-for-byte identical to option 2: one simple cat mark on an opaque, full-bleed background,
without text, a frame or a margin. Its broad features survive the smallest size best.
Options 1 and 5 have more illustrative detail, option 3 intentionally contains the ticker,
and option 4 intentionally has a minted rim and texture; these remain useful alternatives
but were not selected for the stricter primary wallet icon.
